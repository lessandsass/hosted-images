// img-cdn
Hosted on Netlify
Static Asset CDN

Your images.
Delivered fast.

A Netlify-hosted static file repository that serves nested project images via clean, permanent CDN URLs — no backend required.

GET your-site.netlify.app/images/project/folder/image.webp
How it works
01 /

Organise Locally

Nest images inside /images/<project>/ folders on your machine following the agreed structure.

02 /

Push to Netlify

Connect the repo to Netlify. Every push auto-deploys and invalidates the CDN cache globally within seconds.

03 /

Reference by URL

Paste the full Netlify URL wherever you need the image — in code, CMS, Figma, or any external project.

04 /

Always Fresh

Netlify's immutable deploy model means each deployment gets a unique URL so cached references never go stale.

Folder structure
/ (repo root) ├── images/ │ ├── project-alpha/ │ │ ├── icons/ │ │ │ ├── logo.svg │ │ │ └── favicon.png │ │ └── banners/ │ │ ├── hero.webp │ │ └── og-image.jpg │ ├── project-beta/ │ │ └── thumbnail.webp │ └── shared/ │ └── placeholder.svg ├── index.html ← this file └── netlify.toml ← cache headers config
Usage examples
HTML img tag
<img
  src="https://your-site.netlify.app
    /images/project-alpha
    /banners/hero.webp"
  alt="Hero banner"
/>
CSS background
.hero {
  background-image:
    url(
      "https://your-site.netlify.app
      /images/project-alpha
      /banners/hero.webp");
}
JS / React src prop
const CDN =
  "https://your-site.netlify.app";

<img
  src={`${CDN}/images/
    project-alpha/icons/logo.svg`}
/>
netlify.toml cache headers
[[headers]]
  for = "/images/*"

  [headers.values]
    Cache-Control =
      "public, max-age=31536000,
       immutable"
